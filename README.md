# Duck Agency - Next.js Conversion & Responsive Implementation

تحويل موقع **Duck Agency** بالكامل إلى **Next.js (App Router)** مع معالجة التجاوب (Responsiveness) ودعم اللغة العربية (RTL) بشكل مثالي على جميع مقاسات الشاشات (الهواتف الذكية، التابلت، اللابتوب، والشاشات العريضة).

---

## 🚀 المميزات الرئيسية للتحويل

1. **معمارية حديثة مع Next.js (App Router)**:
   - مكونات معيارية مفصولة ومنظمة تحت مجلد `src/components/`.
   - استخدام خط **Cairo** الموصى به رسمياً عبر `next/font/google` لضمان أداء عالي وسرعة تحميل بدون Layout Shift.
   - تهيئة الـ SEO والـ Metadata و Viewport باللغة العربية.

2. **معالجة التجاوب الكامل (Responsive Design)**:
   - **الهيدر والنافبار**: قائمة هاتف ذكية منسدلة (Mobile Drawer) مع زر همبرغر متحرك وقفل تلقائي عند التمرير.
   - **القسم الرئيسي (Hero)**: استبدال العرض الثابت القديم (`851px`) بنصوص متجاوبة بالكامل (`fluid typography`) وأزرار تفاعلية مرنة تتناسب مع الجوال وسطح المكتب.
   - **منصات التكامل**: شبكة متجاوبة تتحول من عمودين في الهواتف إلى 4 أعمدة في الشاشات الأكبر.
   - **بطاقات الخدمات (Services)**: الحفاظ على تأثير الطبقات ثلاثي الأبعاد (`3D Stacked Shadow`) والتأثير الشفاف (`Ghost watermark`) مع ضبط الهوامش لمنع أي قص أو تمرير أفقي على الموبايل.
   - **نافذة تفاصيل الخدمة (Interactive Modal)**: إمكانية النقر على "اقرأ المزيد" للاطلاع على تفاصيل كل خدمة والطلب الفوري عبر واتساب.
   - **رسم الذكاء الاصطناعي (AI Ecosystem Network)**: رسم SVG تفاعلي متجاوب بنبضات وشبكة متصلة، مع بطاقات توضيحية إضافية لسهولة القراءة على الهواتف.
   - **قسم الأرقام والنمو (Metrics)**: عدادات دائرية ومخططات بيانية نمطية متجاوبة بدون أي تشوه.
   - **الفروع والتواصل**: بطاقات واضحة لفرعي القاهرة والرياض مع أرقام قابلة للنقر المباشر (`tel:` و `mailto:`).
   - **الأسئلة الشائعة (FAQ Accordion)**: إجابات قابلة للفتح والغلق لتجربة مستخدم مريحة.
   - **زر واتساب عائم (Floating WhatsApp)**: زر عائم في الأسفل مع تأثير نبض لتسهيل التحويل والمبيعات.

## 📁 هيكل المشروع

```text
new_duck/
├── src/
│   ├── app/
│   │   ├── globals.css         # أنماط Tailwind المخصصة، الـ Keyframes والـ Animations
│   │   ├── layout.tsx          # إعدادات الخط (Cairo)، الـ Metadata، والـ RTL
│   │   └── page.tsx            # الصفحة الرئيسية مجمعة
│   └── components/
│       ├── Navbar.tsx          # القائمة العلوية مع القائمة المتجاوبة للهاتف
│       ├── Hero.tsx            # البانر الرئيسي وخطوط الليزر المتحركة
│       ├── About.tsx           # من نحن وشعار البطة الدائري العصري
│       ├── Integrations.tsx    # منصات المتاجر والإعلانات
│       ├── Services.tsx        # شبكة الخدمات وتأثير الـ 3D Stack والمودال
│       ├── AIEcosystem.tsx     # شبكة الذكاء الاصطناعي التفاعلية
│       ├── Features.tsx        # مميزات تصنع الفرق مع الرسم السيبراني
│       ├── Metrics.tsx         # مؤشرات الأداء (ROAS، المبيعات، الميزانيات)
│       ├── Contact.tsx         # عناوين فروع مصر والسعودية
│       ├── Consultation.tsx    # استمارة الاستشارة والأسئلة الشائعة (FAQ)
│       ├── Footer.tsx          # التذييل، الروابط السريعة وحقوق النشر
│       └── FloatingWhatsApp.tsx# زر واتساب السريع العائم
├── public/
├── next.config.js
├── tailwind.config.js
├── postcss.config.js
├── tsconfig.json
└── package.json
```

## 🛠️ أوامر التشغيل

### 1. تشغيل بيئة التطوير (Development):
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2. بناء المشروع للإنتاج (Production Build):
```bash
npm run build
```

### 3. تشغيل نسخة الإنتاج:
```bash
npm run start
```
